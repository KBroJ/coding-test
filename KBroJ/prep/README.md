# 알고리즘 유형 진행 현황

| # | 유형 | 핵심 키워드 | 경험 |
|---|------|-----------|------|
| 1 | 해시 | 등장 횟수, O(1) 조회 | ✅ 완주하지 못한 선수 |
| 2 | 완전탐색 | N≤20, 모든 경우 | ✅ 괄호없는사칙연산 |
| 3 | 정렬 | 비교, 전처리 | ✅ 삽입정렬 |
| 4 | 스택/큐 | LIFO/FIFO, 괄호, 시뮬레이션 | 🔄 학습 중 |
| 5 | DFS | 모든 경우 탐색, 백트래킹 | ✅ 타겟넘버 |
| 6 | BFS | 최단 거리 보장 | ✅ 게임맵최단거리 |
| 7 | DP | 점화식, 메모이제이션 | ✅ 피보나치수2 |
| 8 | 그리디 | 매 순간 최선, 정렬 후 선택 | ⏳ 예정 |
| 9 | 힙(Heap) | 최솟값/최댓값 반복 꺼냄 | ⏳ 예정 |
| 10 | 이분탐색 | 정렬된 배열, O(log N) | ⏳ 예정 |
